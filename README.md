## 🚀 Premium Features

- **Dual-Portal Framework:** Clean, multi-page layout architecture with native `href` navigation routing between Class 9 and Class 10 workspaces.
- **Full Syllabus Trackers:** Complete chapter breakdowns for **Physics, Chemistry, Biology, and Mathematics** following strict NCERT syllabus guidelines.
- **Reference Book Hub:** Curated learning paths divided into *Basics* (for clearing school boards) and *Advanced* (for competitive foundations like NTSE, JEE, and Olympiads/IOQM).
- **Secure AI Doubt Bot:** Floating chat widget powered securely via Chatbase (utilizing the *GPT-4o Mini* engine). It is custom-prompted to behave as an expert CBSE teacher that renders beautiful inline math formulas.
- **Interactive Study Planner:** Built-in productivity planner backed by browser `LocalStorage` API to ensure daily student goals and study tasks never vanish on page reloads.
- **Google Indexed:** Fully verified and connected to *Google Search Console* with custom sitemaps for organic search visibility.

---

## 🛠️ Tech Stack & Architecture

- **Frontend Core:** Plain HTML5 semantics for fast loading structures.
- **Styling Architecture:** Modern CSS3 layout styling incorporating slate-dark accents, responsive flex-grid layouts, and sleek capsule toggle animations.
- **Logic Engine:** Vanilla JavaScript handling client-side dynamic tab-switching and responsive element states with zero page-reload delays.
- **Data Persistence:** JavaScript Browser `LocalStorage` data mapping arrays to store planner pipelines locally.
- **Deployment Platform:** Hosted publicly on the edge via **GitHub Pages**.
